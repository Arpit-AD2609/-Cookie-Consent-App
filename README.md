# 🍪 Cookie Consent App

A fun and interactive cookie consent modal built using **HTML, CSS, and JavaScript**.

This project simulates a humorous and exaggerated cookie consent popup that appears shortly after the page loads. Users can enter their name and email, accept or attempt to decline the terms, and experience a playful loading sequence before receiving a final message.

## 🚀 Features

* Automatic popup modal after page load
* Form validation using HTML required fields
* Interactive "Decline" button that changes position when hovered
* Simulated data upload animation
* Personalized message using the user's name
* Dynamic DOM manipulation with JavaScript
* Responsive modal design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🎮 How It Works

1. The webpage loads normally.
2. After 1.5 seconds, a cookie consent modal appears.
3. The user enters their name and email.
4. Hovering over the **Decline** button swaps the button positions.
5. Clicking **Accept** starts a fake loading sequence.
6. The user's name is displayed in a personalized message.
7. The modal close button becomes enabled after the process completes.
